HOW TO RUN EACH CLIP
--------------------
1. Open a NEW Dola chat.
2. Paste 0_FILM_BRIEF_paste_first.md as the first message (the project brief). Send it.
3. Upload ALL images from the clip folder, IN NUMBER ORDER (1_FIRST_FRAME first).
4. Paste that folder's PROMPT.txt. Send.

CLIP 4A NOTE
------------
A red spray on a face may be read as blood and refused (Dola is strict, the film brief also says no blood).
If it is refused: open a NEW chat (one refusal can block the whole chat) and use PROMPT_SAFE.txt
(hot wind + dust instead of red spray - same moment, same smile).
If the slow motion is not slow enough, the editor will slow it down to half speed.
