THE ONE-EYED ISLAND - GOAT SCENE PACK FOR DOLA (works on a brand-new account)
=============================================================================
Dola cannot open zip, .txt or .md attachments. It only reads IMAGES and PASTED TEXT.

1. Unzip this file on your PC (right-click > Extract All).
2. For each clip folder (CLIP3, CLIP4A, CLIP4B), open a NEW Dola chat and:
   a) drag in the folder's images in number order (1_FIRST_FRAME first),
   b) open PASTE_THIS_IN_DOLA.txt in Notepad, Ctrl+A, Ctrl+C, paste it in the chat, send.
   That one paste already contains the whole project brief + the scene story + the prompt,
   so a new account understands everything. Nothing else is needed.
3. The 3 clips have their own first frames -> you can run them at the same time.

CLIP 4A: if the red spray is refused, open a NEW chat and use PASTE_THIS_IN_DOLA_SAFE.txt
(hot wind + dust instead of red spray).

Do NOT let Dola stitch or merge clips (Fast/Pro) - send the clips back and they get joined for free.
